RCN WORKSHOP (BETA) - PIERWSZE KROKI
=====================================

Dziękuję za udział w testach!

1. URUCHOMIENIE

Uruchom program skrótem "RCN Workshop" (pulpit lub menu Start). Otworzy się
natywne okno aplikacji - pierwszy start może potrwać kilkanaście sekund.
Przy pierwszym uruchomieniu danej wersji zobaczysz okno ostrzegawcze o wersji
testowej - przeczytaj i kliknij "Rozumiem, przechodzę dalej".

2. DOGRANIE DANYCH (WORKSPACE)

Program po instalacji nie zawiera danych. Powiat (workspace) dodasz na dwa
sposoby:
  a) NAJPROŚCIEJ: na liście workspace'ów kliknij "Wgraj .zip" i wskaż paczkę
     otrzymaną od autora - program sam ją rozpakuje i doda do listy;
  b) ręcznie: skopiuj cały folder powiatu do C:\RCN Workshop\workspaces\
     i odśwież listę w programie.

3. GDZIE SĄ MOJE DANE

Wszystkie dane trzymane są lokalnie w C:\RCN Workshop\workspaces\.
Program niczego nie wysyła do internetu. Notatki i kolekcje zapisują się
w plikach obok bazy powiatu.

4. AKTUALIZACJA DO NOWEJ WERSJI

Pobierz nowszy instalator i uruchom go "na wierzch" - nie musisz niczego
odinstalowywać. Jeśli program jest otwarty, instalator poprosi o jego
zamknięcie. Twoje workspace'y i notatki ZOSTAJĄ nietknięte.
Odinstalowanie programu również NIE kasuje danych w workspaces.

5. ZGŁASZANIE BŁĘDÓW I UWAG

Każda uwaga jest cenna - także "to jest nieintuicyjne" albo "tego mi brakuje".
  - W aplikacji: link "Podziel się opinią" (jeśli widoczny) prowadzi do
    formularza zgłoszeń.
  - Przy zgłoszeniu błędu opisz: w którym miejscu programu, co kliknąłeś,
    co się stało zamiast oczekiwanego wyniku.
  - Jeśli program nie wstaje lub pada: dołącz plik C:\RCN Workshop\rcn-server.log
    (to dziennik serwera - bardzo przyspiesza diagnozę).

Miłego testowania!
